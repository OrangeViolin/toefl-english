# 写作表达库

写作专用的**句型 / 连接词 / 套话**库，按功能场景分组，考场直接调用。配套「单词走背词计划」——写作单词汇入 `背词计划/data/项目生词.json`（标"写作"），表达进这里。

> 定位：写作**练习**在考拉考拉平台做；这里只做**知识库积累**。不建写作练习系统。

## 功能

- 按场景分组（立场/让步/转折/给理由/举例/解释/收尾 + 邮件问候/请求/收尾/陈述目的…）
- 每条：英文表达 + 中文 + 🧭 用法/语域 + 例句 + 🔊 美音朗读
- 🙈 背记模式（遮中文自测）· 场景筛选 · 掌握进度（**绑稳定 id，重建不丢**）
- ⬇ 导出备份 / ⬆ 导入（进度永不被抹，吸取标记丢失教训）

## 积累工作流（每次考拉考拉练完）

1. 你把想留的**表达**发我（或连同你的作文+AI润色版）→ cc 归到对应场景 `data/表达库.json` 的 `items[]`（每条给稳定 id）→ `python3 build.py` 重建。
2. 想留的**单词** → 走背词计划「项目生词」（标"写作"）。
3. **话术**：「写作表达库加：<表达/场景>」。

## 架构

```
写作表达库/
├─ build.py          # 渲染器：data/表达库.json → index.html
├─ data/表达库.json  # 场景+表达（事实来源，每条稳定 id）
├─ index.html        # 自包含，双击即用
└─ README.md
```
