# 写作案例库（知识库·整体层）

写作知识库分两层，这是**整体层**：每次写作训练存一条**完整案例**，保留全上下文。

| 层 | 装什么 | 在哪 |
|---|---|---|
| **零散层** | 拆出来的**表达**（可复用句型/连接/套话）+ **单词** | `写作表达库/`（表达）+ `背词计划/项目生词`（词，标"写作"）|
| **整体层** | 每次训练的**完整案例**（题目+三版答案）| **本目录** `写作案例库/` |

## 每条案例存 4 样（缺一不可）

1. **题目**
2. **我的原答案**（+ 用时、cc 评估 band）
3. **其他 AI 润色的答案**
4. **cc 给我的修改版**（**~70 词**，贴我真实打字速度，扎实 band 4，背这版）
5. （附）本案例沉淀出的**表达 / 单词**，指向零散层

## 工作流（每次考拉考拉练完）

发我 **题目 + 我的原答案 + 其他 AI 润色版** → cc：① 诊断原答案 → ② 出 **~70 词修改版** → ③ **存一条本目录案例（4 样齐全）** → ④ 抽好表达进 `写作表达库` → ⑤ 抽好词进 `背词计划/项目生词`（标"写作"）。
