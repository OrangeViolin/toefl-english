# 托福写作专项系统

新版 iBT 写作三题型的**专注刷练**站（模考系统只有整场、写作题量少且无模板，这里补齐）。全离线、双击 `index.html` 即开。

## 三个模式

| 模式 | 题型 | 判分 | 特色 |
|---|---|---|---|
| 🧩 连词成句 | Build a Sentence | **自动对错** | 重排词块成句，当场判分 + 正确句 + 语法点；按 A1→C2 排序 |
| ✉️ 写邮件 | Write an Email | 官方 0–5 | 情景 + **万能框架 + 高频句** + 7 分钟计时 + 一键复制报告给 cc |
| 💬 学术讨论 | Write for an Academic Discussion | 官方 0–5 | 教授贴+两同学贴 + **立场论证框架** + 10 分钟 + ≥100 词 + 复制报告给 cc |

主观作答（邮件/讨论）不在页面判分，而是**「复制报告给 cc」→ 贴回对话，由 cc 按官方 0–5 量规打分并改**。

## 架构（与其它系统一致）

```
写作系统/
├─ build.py                 # 唯一渲染引擎，别手写 HTML
├─ data/build-sentence.json # 连词成句题库（事实来源）
├─ data/email.json          # 邮件情景 + 模板
├─ data/discussion.json     # 讨论话题 + 模板
├─ index.html               # 产出：自包含，双击即开
└─ README.md
```

改数据 → 跑 `python3 build.py` → 刷新 `index.html`。

## 加题话术

- 「**写作系统加句**：<语法点/难度>」→ 往 `build-sentence.json` 加连词成句题。
- 「**写作系统加邮件/讨论**：<主题>」→ 往对应 JSON 加情景/话题。

## 判分依据

官方 0–5 量规与 band 换算，与 `模考系统/新版题型与评分规范.md` 一致；连词成句为对/错（每题 1 分，占写作 10/20 分）。
