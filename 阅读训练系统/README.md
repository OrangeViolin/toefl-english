# 📖 托福阅读训练系统

一个「**左边读文章 · 右边逐题刷 · 用括号法划句子成分**」的托福阅读练习站。
纯前端、自包含 HTML，双击即用，无需联网、无需服务。

## 怎么用

1. 双击 `index.html` 打开总目录 → 点任意一篇文章。
2. **左栏**是文章，可自由上下滚动、反复看；**右栏**一道一道刷题（◀ ▶ 或键盘 ← → 切题）。
3. 选好答案点「提交」→ 立刻出对错 + **中文解析**；全部提交后显示本篇得分。
4. 点右上「定位原文 ▸」可把左栏滚到当前题对应的段落并高亮。

## ✍️ 括号法标注（核心功能）

按你平时分析句子成分的习惯设计：

- **在左栏用鼠标划选**任意一段文字 → 弹出小工具条 → 点对应的**括号 / 标记**：

  | 标记 | 括号 | 颜色 | 用途 |
  |------|------|------|------|
  | 主干 S·V·O | 下划线 | 红 | 句子骨架 |
  | 从句 | `[ ]` | 蓝 | 定语/宾语/主语从句 |
  | 修饰 / 短语 | `( )` | 绿 | 介词短语·分词·后置定语 |
  | 插入 · 同位语 | `{ }` | 紫 | 插入语/同位语/破折号成分 |
  | 生词 · 难点 | 高亮 | 黄 | 标黄回看 |

- **括号可以嵌套**：把从句、短语、插入语逐层括起来，剩下没括的就是**主干**——这正是括号法拆长难句的思路。
- 标注**自动保存**（localStorage），滚动来回、关掉再开都还在。
- **删除**：点一下括号本身即可删除那条标注；或划选后点工具条里「清除」；右上「清空标注」清空全篇。
- 右下「图例」随时查看各标记含义；「A±」调字号；顶栏计时器默认 18 分钟倒计时（点击开始/暂停）。

## 文章难度

全部按**托福真实学术难度**原创撰写（★★★★ 起）：学术说明文、650–780 词、每段多个长难句，
题型对齐官方（事实信息 / 否定事实 / 推断 / 修辞目的 / 词汇 / 指代 / 句子简化 / 句子插入 / 内容总结）。
每篇 10 题、每题带中文解析。

> 说明：为规避版权，题库为**对齐真实难度与题型的原创仿真文章**，非 ETS/TPO 原题。
> 想加真题只需按规范补一个 JSON 即可（见下）。

## 目录结构

```
阅读训练系统/
├─ index.html          # 总目录（双击打开这个）
├─ build.py            # 渲染器：data/*.json → passages/*.html + 刷新 index.html
├─ data/               # 事实来源：每篇文章 = 一个 JSON
│   ├─ glass-sponges.json
│   └─ …
├─ passages/           # 生成的自包含阅读页（可直接双击 / 分享）
│   └─ glass-sponges.html
├─ 阅读文章规范.md      # passage JSON schema + 难度 / 题型标准（加新文章照这个写）
└─ README.md
```

## 加一篇新文章

1. 照 `阅读文章规范.md` 在 `data/` 下写一个 `<id>.json`（有黄金范文 `glass-sponges.json` 可参照）。
2. 运行：

   ```bash
   cd 阅读训练系统
   python3 build.py
   ```

3. 刷新 `index.html` 即可看到新文章。（想让我写，直接说「阅读系统加一篇：<学科/主题>」。）
