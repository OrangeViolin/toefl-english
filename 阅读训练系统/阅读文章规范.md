# 托福阅读文章规范（passage JSON schema + 难度 / 题型标准）

每一篇文章 = `data/` 下的一个 JSON 文件。跑 `python3 build.py` 后自动渲染成
`passages/<id>.html`（自包含，可直接双击 / 分享），并刷新 `index.html` 目录。

写新文章时**严格按本规范**，保证难度对齐真实托福、题型齐全、答案可判。

---

## 一、难度标准（核心：必须是"真·托福难度"）

托福阅读的难点不在生词，而在**学术文章的信息密度和长难句**。一篇合格的文章要满足：

- **体裁**：学术说明文 / 议论文，第三人称客观语气。禁止口语、故事、鸡汤。
- **领域**：只在托福高频学科里选——生物、地质 / 地球科学、天文、环境、历史、
  考古 / 人类学、艺术史 / 建筑、心理 / 社会科学、经济史、科技史。
- **长度**：`650–780` 词，`4–6` 段。段落之间有清晰的逻辑推进（现象→机制→争论→例证）。
- **句子**：每段至少 2–3 个**长难句**（从句嵌套、插入语、后置定语、被动、名词化）。
  这是给"括号法"练习用的核心素材，务必写出真实的语法复杂度。
- **信息**：出现具体的机制、数据、时间、对立假说、专有名词。禁止空泛铺陈、禁止水句。
- **难度自评** `difficulty`：`1–5`，本系统只收 **4–5**（偏难，托福真实到偏上）。

## 二、题型标准（每篇 10 题，题型配比对齐官方）

一篇标准托福文章 10 题，建议配比：

| 题型 `type`            | 中文        | 数量  | 说明 |
|------------------------|-------------|-------|------|
| `factual`              | 事实信息    | 2–3   | 直接在原文找依据 |
| `negative_factual`     | 否定事实    | 1     | "以下哪个 NOT / EXCEPT" |
| `inference`            | 推断        | 1–2   | 原文没明说，需合理推理 |
| `rhetorical_purpose`   | 修辞目的    | 1     | 作者"为什么"提到某内容 |
| `vocabulary`           | 词汇        | 1–2   | 划词，选最接近词义 |
| `reference`            | 指代        | 0–1   | 划出代词，问指代对象 |
| `sentence_simplification` | 句子简化 | 1     | 高亮一句长句，选保留核心信息的改写 |
| `insert_text`          | 句子插入    | 1     | 段落里 4 个 ■ 方块，插一句到最合适处 |
| `prose_summary`        | 内容总结    | 1     | 6 选 3，选最重要的三个概括（**最后一题**） |

- 单选题 `answer` = 正确项下标（0=A,1=B,2=C,3=D）。
- `prose_summary` 的 `answer` = 三个下标的数组，如 `[0,2,4]`。
- 每题必须有 `explain`（中文解析：为什么对 + 为什么其余错 / 定位到原文哪句）。

## 三、JSON 字段

```jsonc
{
  "id": "glass-sponges",              // 文件名 / URL，用小写连字符
  "title": "Glass Sponges of the Deep Sea",
  "domain": "生物",                    // 中文领域名，见上表
  "difficulty": 4,                     // 4 或 5
  "est_words": 730,                    // 正文词数（大致）
  "intro": "可选：一句斜体背景引言（对应托福正文前的灰字导语）",

  "paragraphs": [
    { "n": 1, "text": "段落纯文本……" },
    { "n": 2, "text": "……" }
    // insert_text 题所在段落里，用 4 个全角 ■ 方块标出候选插入位置：
    // "text": "……。■ 首句之后。■ 又一句。■ 再一句。■ 末句之后。"
  ],

  "glossary": [                        // 可选，脚注生词（对应托福正文下方的 Glossary）
    { "term": "spicule", "def": "a tiny needle-like skeletal element" }
  ],

  "questions": [
    {
      "type": "vocabulary",
      "stem": "The word <b>\"intricate\"</b> in paragraph 2 is closest in meaning to",
      "para": 2,                       // 定位段号；点"定位原文"会滚过去并高亮
      "highlight": "intricate",        // 可选：在原文里高亮这个词/这句（词汇/指代/句子简化题必填）
      "options": ["complex", "fragile", "ancient", "hidden"],
      "answer": 0,
      "explain": "intricate＝错综复杂，与 complex 同义。原文指骨架结构精细复杂……"
    },
    {
      "type": "insert_text",
      "stem": "Look at the four squares [■] in paragraph 4. Where would the following sentence best fit?",
      "para": 4,
      "insert_sentence": "This trapped silica, however, comes at a metabolic cost.",
      "options": ["方块 ①", "方块 ②", "方块 ③", "方块 ④"],
      "answer": 2,
      "explain": "该句以 however 转折并承接上句的 silica，应放在第③个方块……"
    },
    {
      "type": "prose_summary",
      "stem": "Complete the summary by selecting the THREE answer choices that express the most important ideas in the passage.",
      "intro_sentence": "Glass sponges thrive in the deep sea by building silica skeletons.",
      "options": ["…6 个选项…"],       // 6 项
      "answer": [0, 2, 4],             // 选 3
      "explain": "①②主旨；③④为细节 / 未提及……"
    }
  ]
}
```

## 四、写作检查清单（交稿前逐条核对）

- [ ] 正文 650–780 词、4–6 段、每段有长难句、无水句。
- [ ] 10 题、题型配比合理、最后一题是 `prose_summary`。
- [ ] 每个 `answer` 在原文 / 逻辑上唯一可判；干扰项各有其"像是对"的理由。
- [ ] `vocabulary` / `reference` / `sentence_simplification` 都填了 `highlight`。
- [ ] `insert_text` 段落里正好 4 个 ■，且 `answer` 指向正确方块。
- [ ] 每题 `explain` 写清了定位与排除。
- [ ] `id` 唯一、`domain` / `difficulty` / `est_words` 填全。
