# 📚 背词计划

从原 `english-learner.html` 的「背词计划」迁移而来，**做了极简**：只保留
**「按 List 分组 → 一组一组过词 → 掌握进度」**，去掉了每日计划、循环、打卡等一切多余功能。
UI 换成本项目的暖色纸感。纯前端、自包含单文件，**双击即用**、离线。

## 怎么用

1. 双击 `index.html`。
2. 顶部切词库：**绿皮书（4264 词 / 48 组）** 或 **BEAT 2000（2100 词 / 30 组）**。
3. 总览是一格格的 **List**，点一组进去过单词：
   - **默认收起**，一行一个词（单词 + 音标 + 词性 + 释义 + 标记），方便从头到尾快速浏览。
   - **点一个词展开**，显示详细信息。已按 **voca 标准富化**的词会展开完整卡片：🏛 造词来源·词源故事 / 🗣 发音规律 / 💡 记忆钩子 / ✍️ 造句·名著例句·高频搭配 / 🔗 近义词辨析·反义词(可点🔊) / 🎯 辨析总结；未富化的词先回退显示词库自带的 词根记忆/搭配/例句。再点收起。（点单词本身是 🔊 朗读，不会展开。）
   - 每个词可标 **✓ 掌握** 或 **✕ 未掌握**（三态：默认未学 / 已掌握 / 未掌握；再点一次取消，两者互斥）。组内「掌握 / 未掌握」计数与顶部总进度实时更新，**自动本地保存**。
4. 工具：
   - **背记模式**：连释义一起收起、只看英文，点卡片再显现（自测）。
   - **展开 / 收起全部**：一键把整组词全部展开或收起。
   - **筛选 全部 / 未掌握 / 已掌握**：只挑标了「未掌握」的生词重点复习。
   - **上一组 / 下一组**：一组接一组顺着过。
   - **本组·其余记为已掌握**：把本组里没标「未掌握」的词一键记为已掌握（标了未掌握的保留）。
   - 顶部**搜单词**：跳到它所在的 List。
5. **浏览完的高效标记法**：一路只把不会的点「未掌握」，其余不用逐个点——
   - 单组过完：点该组的「本组·其余记为已掌握」；
   - 整本过完：回总览点「✅ 其余一键记为『已掌握』」，把整个词库里没标未掌握的词全部记为已掌握。

## 目录结构

```
背词计划/
├─ index.html          # 生成的自包含背词页（双击这个）
├─ build.py            # 渲染器：data/*.json → index.html（内嵌精简词库）
└─ data/               # 词库源数据
    ├─ green-book.json   # 绿皮书 4264 词
    └─ beat-vocab.json   # BEAT 2100 词
```

## 重新生成 / 更新词库

改了 `data/` 里的词库后：

```bash
cd 背词计划
python3 build.py
```

会把两个词库精简内嵌，重新生成 `index.html`。

> 说明：进度存在浏览器 localStorage（键 `bcplan:mastered`），换浏览器/清缓存会重置。
> 与 `单词记忆系统/`（按发音规律·词根分组的拆解卡片墙）互补：这里是**按词书 List 顺序刷完整词库**。
