# 六级 · 托福单词记忆系统

一个「按你自己的逻辑分组 → 每组一张拆解卡片墙」的背单词系统。

## 两个能力

1. **我帮你整合词**：你不用操心词表从哪来。
   - 托福：来自真实的 **4264 词托福词库**（`toefl_wordlist`）。
   - 六级：用六级核心词补齐，并标注等级（六级 / 托福 / GRE拓展 / 基础）。
2. **你按逻辑点单**：直接给我一条规则，我就新建一组卡片墙。例如：
   - 拼写/发音：「含 `aw` 的词」「以 `-tion` 结尾」「`ough` 的几种读音」
   - 词根：「表示『看』的 `spect / vis / vid` 一家」
   - 语义近义：「`easy / difficult` 近义反义一组」
   - 话题：「学术写作高频动词」

## 每张卡片包含

音标 · 造词来源（词源故事）· 词根词缀 · 发音规律 · 记忆钩子 · 造句 + 名著/影视真实例句。

## 学习页自带功能

- 🔊 **点词发音**（浏览器语音合成）
- **核心 / 例外发音规律**双栏对照
- 🎵 **同韵顺口溜**：把同韵词成串排列，点着念最快
- **按等级 / 读音筛选** + 关键词搜索
- 🧠 **记忆模式**：模糊释义做自测，悬停/点击显形
- ✅ **已掌握进度**：勾选后本地保存，进度条实时更新（localStorage）

## 目录结构

```
单词记忆系统/
├─ index.html          # 总目录（双击打开这个）
├─ build.py            # 渲染器：data/*.json → groups/*.html
├─ data/               # 事实来源：每个 JSON = 一组词
│   └─ aw.json
├─ groups/             # 生成的学习页（自包含，可直接双击/分享）
│   └─ aw.html
└─ 单词拆解卡片-规范.md  # 卡片字段与质量标准（生成新组的统一模板）
```

## 用法

```bash
python3 build.py          # 渲染全部组
python3 build.py aw       # 只渲染 data/aw.json
```

生成的 `groups/*.html` 是**自包含**的：数据内嵌，双击即开，可单独发给手机/朋友，无需联网、无需服务器。
