# 单词拆解卡片 · 规范（统一标准）

> 这份标准已固化为可复用 skill：`~/.claude/skills/单词学习页/`。
> 以后任何单词学习页都按此标准由 `build.py` 生成，**绝不手写 HTML**。

每建一组新词，都按这张规范填 `data/<组名>.json`。目标：**把每个单词拆到极其清晰**，让规律、故事、例句三管齐下地帮记忆。

## 组级字段

```jsonc
{
  "id": "aw",                 // 文件名/URL，用小写英文
  "combo": "aw",              // 卡片高亮的核心（字母组合/词根/主题符号）
  "title": "aw 同音家族",
  "sound": "/ɔː/",            // 该组的核心读音（无统一读音时填主题名）
  "subtitle": "一句话卖点",
  "intro": "3–5 句：这组的记忆逻辑是什么、为什么好记",
  "rules": {
    "core": "主规律（正例）——发音/构词要领 + 口型或动作描述",
    "exception": "反规律（陷阱）——同形不同音/不规则的情况"
  },
  "rhymeChains": [            // 可选：同韵/同型串记，点词发音成串背
    { "label": "-aw 结尾", "words": ["raw","saw","law"] }
  ],
  "words": [ /* 见下 */ ]
}
```

## 单词字段

```jsonc
{
  "word": "awful",
  "levels": ["六级","托福"],       // 六级 / 托福 / GRE拓展 / 基础，可多标
  "ipa": "/ˈɔːfl/",
  "subgroup": "core",             // core=符合主规律 / exception=例外
  "meaning": "adj. 糟糕的…",       // 词性+核心义，简练
  "etymology": "造词来源与故事：本义→词义演变，越有画面越好",
  "roots": [ {"part":"awe","meaning":"敬畏"}, {"part":"-ful","meaning":"充满…的"} ],
  "phonetics": "发音规律：这个组合怎么读、易错点在哪",
  "tip": "可选 · 一句记忆钩子（联想/拆分/对比）",
  "examples": [
    {"en":"…","zh":"…","source":"造句"},                 // 自然学习例句
    {"en":"The Awful Truth","zh":"…","source":"电影片名"}  // 文化锚点
  ]
}
```

## 质量红线（对齐 CLAUDE.md：高信息密度、禁水句）

- **每个字段都要推进记忆**，不写「这是一个常见词」这类废话。
- **词源要真、要有故事**：讲清本义与词义演变，能勾连同源词更好（如 raw–crude–cruel）。
- **例句诚实**：
  - `source` 为「造句」= 我写的学习例句，据实标注，不冒充名句。
  - 文化锚点（电影片名 / 名著 / 名句 / 习语）**必须是真实出处**并写明来源；拿不准就退回「高频搭配」，标 `source:"高频搭配"`，**绝不编造虚假引文**。
- **发音规律要点到陷阱**：如 `gnaw` 的 g 不发音、`awry` 的 w 不发音、`award` 的 aw 被音节切开。
- **例外单独归组**（`subgroup:"exception"`），让「规律 + 陷阱」一次学透。

## 每页自带的标准功能（由 build.py 统一保证）

- 🧩 单词拆解卡片：音标·词源故事·词根词缀·发音规律·记忆钩子·造句+名著/影视真实例句
- 🔗 近义词辨析·反义词：每词 2–4 近义词 + 反义词（可点🔊）+ 一句用法辨析，学一个带一串
- 🔊 美式女声朗读（可切换音色）· 🎵 同韵顺口溜串记
- 🔎 按等级/读音筛选 + 搜索 · 🧠 记忆模式（模糊释义自测）· 🔺 不熟悉标记（变色+置顶，localStorage；配「只看不熟悉」筛选，与测验联动）
- 📝 **检测系统（英译中四选一）**：覆盖当前筛选到的全部单词；给英文+音标+🔊 → 4 个中文释义选项（1 正确 + 3 同组干扰项）；即时对错；按 1–4 键作答、回车下一题；结束给分数/正确率/错题清单，可「只测错题」或「再来一轮」。
