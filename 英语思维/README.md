# 英语思维 · English Mind

沉浸轴模块之一。专门拆**英语的思维方式 vs 中文思维**——很多"说不地道"的根子不在词汇，在于句子怎么组织、先说什么、把谁当主角。**入口页**：`index.html`（思维卡，自包含、点英文例句可朗读）。

## 是什么

每张「思维卡」= 一个英语思维模式：
- **本质**：一句话说清这个模式。
- **中 ↔ 英对照例**：同一个意思，中文思维怎么想 / 英语思维怎么说。
- **怎么用**：一条可迁移的操作口诀。

首批 12 张：结论先行 · 主语驱动 · 名词化 · 时态即世界观 · 直接表达 · 逻辑连接显性 · 冠词与可数 · 被动求客观 · 具体动词优先 · 情态即态度 · 一句一核心 · 平行结构。

## 怎么加

话术 `英语思维加一张：<模式>`（如「英语思维加一张：抽象名词当主语」）。cc 按同一卡片结构追加进 `index.html` 的 `CARDS` 数组。后续卡片多了可拆成 `data/*.json → build.py`（先内联，够用）。

## 关联

- 和 [日常表达](../日常表达/) 互补：思维卡讲"怎么想"，日记练"真的这么写"。
- 出现的实词按项目铁律汇入 `背词计划`。
