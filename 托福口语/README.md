# 托福口语模拟训练系统

对标 **2026 新版 iBT 口语**（2026-01-21 改版后）的两类题型：听力复述 + 面试问答。

## 两个题型

| 页面 | 题型 | 题量 | 考什么 | 系统自动做什么 |
|---|---|---|---|---|
| `听力复述.html` | Listen and Repeat | 8 场景 × 7 句（场景内难度递增） | 发音、重音、节奏、短时记忆 | TTS 播放原句 → 录音 → **本地 whisper 转写** → 逐字比对算复述准确率 |
| `面试问答.html` | Take an Interview | 5 主题 × 4 问 | 流利度、连贯、语法词汇、韵律 | 45s 倒计时 → 录音 → 转写 → 算语速/时长/填充词 |

## 怎么启动（重要）

录音转写用的是**本地 faster-whisper 语音识别**（离线、比浏览器准得多）。启动方式：

1. **双击 `start.command`** —— 自动后台启动转写服务 + 用 Chrome 打开页面。
2. 页面通过固定地址 `http://127.0.0.1:8765/` 访问（不是 file://），首次录音点「允许」一次麦克风权限，**之后永久记住，不再弹窗**。
3. 练习完双击 `stop.command` 停止服务（不关也行，下次 start 会自动重启并加载最新代码）。

> 第一次启动会自动下载英文识别模型（~145MB，仅一次）；之后秒开。
> 若麦克风权限仍每次弹，到 Chrome「设置 → 隐私和安全 → 网站设置 → 麦克风」，把 `127.0.0.1` 设为「允许」即可。

## 录音 → 打分闭环

1. 题型页里：播放/出题 → 点「开始录音」→ 说 → 「停止」。
2. 停止后页面显示「转写中…」，然后给出**转写文字 + 语速/时长 + 本句 0–5 估分**。
3. 点「复制答题报告」，把报告**贴回和 cc 的对话**，cc 给分维度打分 + 改进建议。

## 听力复述评分标准（对标官方 Listen and Repeat）

- **每句独立打 0–5 分**（整体性评分，非扣分制），维度：**清晰度 50% + 一致性 50%**。
- 档位：5 完全一致（±0 词）· 4 语义一致（±1–2 词替换）· 3 结构完整（±3 词）· 2 内容缺失（±4–5 词）· 1 仅个别词 · 0 无效（空白/非英语/无关）。
- 一套 = 一个场景 7 句，**原始分满 35** → 折算 **0–6** 的 section 分。
- 系统据转写只能**估「一致性」**（词级编辑距离 → 0–5）；**清晰度**（发音好不好懂）由 cc 结合录音反馈或你自评，二者各半得最终 0–5。页面顶部「📊 评分标准」折叠卡内有完整表格。

## 转写引擎（诚实说明）

- **主引擎**：本地 faster-whisper（base.en 模型），离线、准确。录音→录完统一转写（不再是边录边识别）。
- **降级**：若本地服务没启动，自动回退浏览器 Web Speech API（可能不准），页面会明确提示「⚠️ 浏览器降级识别」。
- **发音/口音层面 cc 打不了分**：cc 基于转写文字和流利度指标打内容/语言/连贯/复述准确分；发音口音分需你自查或另接语音评分引擎。

## 技术依赖

- 录音：MediaRecorder API（浏览器）
- 语音转写：本地 faster-whisper（Python 服务，`transcribe_server.py`，监听 127.0.0.1:8765）
- 朗读：speechSynthesis（美式女声）
