# 托福口语模拟训练系统

对标 **2026 新版 iBT 口语**（2026-01-21 改版后）的两类题型：听力复述 + 面试问答。

## 两个题型

| 页面 | 题型 | 题量 | 考什么 | 系统自动做什么 |
|---|---|---|---|---|
| `听力复述.html` | Listen and Repeat | 14 句（难度递增） | 发音、重音、节奏、短时记忆 | TTS 播放原句 → 录音 → 语音转写 → **逐字比对算复述准确率** |
| `面试问答.html` | Take an Interview | 5 主题 × 4 问 | 流利度、连贯、语法词汇、韵律 | 45s 倒计时 → 录音 → 转写 → 算语速/时长/填充词 |

## 使用方法（录音 → 打分闭环）

1. **用 Chrome / Edge 打开**（语音转写依赖 Web Speech API；首次录音需允许麦克风）。
2. 打开对应题型页 → 播放/出题 → 点「开始录音」对着麦克风说 → 「停止」。
3. 系统自动把你说的转成文字、算语速/时长等指标。
4. 点「复制答题报告」，把报告**贴回和 cc 的对话**，cc 给分维度打分 + 改进建议。

## cc 怎么打分（分维度，对标 ETS SpeechRater）

- **听力复述**：复述准确率（逐字比对）+ 流利度（语速）；发音/韵律 cc 无法从转写文本判断，需你自查或后续接真语音评分。
- **面试问答**：流利度（语速、时长、填充词）+ 连贯展开 + 语法词汇 + 韵律。

> ⚠️ 诚实说明：cc 是文字模型，**不能直接听音频**。系统把「声音 → 文字 + 流利度指标」这一步做了，cc 基于转写文本和指标打内容/语言/连贯分。发音与口音层面的分，需另接语音评分引擎（本地无 whisper）。

## 技术依赖

- 录音：MediaRecorder API
- 语音转写：Web Speech API（Chrome 云端 ASR，免费、无需安装）
- 朗读：speechSynthesis（美式女声）
- 数据：内嵌于各 HTML 页，双击即开、离线可用（转写需联网）
