# 📝 托福模考系统（新版 iBT · 2026）

一套**整场连考 / 单项专项**两用的托福模考。严格按 **2026 新版 TOEFL iBT**（官方《Updated TOEFL iBT Test Overview》）的
9 大题型、考试顺序与评分标准做仿真：**阅读 → 听力 → 写作 → 口语**，最后出 **1–6 band + 总分 + CEFR**。
纯前端、自包含 HTML，双击即用，**离线**（听力用浏览器语音合成、口语用浏览器录音，无需联网/API）。

## 怎么用

1. **用 Chrome / Edge** 双击 `index.html` → 点一套模考。
2. 进去先看菜单，三种玩法：
   - **▶ 开始整场模考**：四科连考、分科计时，最后出各科 band + 总分 + CEFR。
   - **按科目练**：单独刷阅读 / 听力 / 写作 / 口语。
   - **按题型练**：9 种新题型任意单练。
3. 客观题（阅读 / 听力 / 连词成句）**自动判分并估算 band**；写作与口语作答按官方 **0–5 量规**——点「复制评分报告给 cc」把作答贴回来，我依量规打分，你再把 0–5 填回成绩单，即可算出四科 band + 总分。

## 新版 9 大题型（全部已实现）

| 科目 | 题型 | 交互 |
|------|------|------|
| 阅读 | **Complete the Words** 补全单词 | 段落内挖空，填缺失字母，自动判分 |
| | **Read in Daily Life** 生活阅读 | 短信/通知等 + 2–3 选择题 |
| | **Read an Academic Passage** 学术短文 | ~200 词 + 5 选择题 |
| 听力 | **Listen & Choose a Response** 选回应 | 只**听**一句(TTS)→四选一，原文不显示 |
| | **Listen to a Conversation** 对话 | 双人对话(双音色)→2 题 |
| | **Listen to an Announcement** 通知 | 校园通知→2–3 题 |
| | **Listen to an Academic Talk** 讲座 | 100–250 词短讲→4 题 |
| 写作 | **Build a Sentence** 连词成句 | 点词组拼句，自动判对错 |
| | **Write an Email** 写邮件 | 情景 + 7 分钟计时 + 字数 |
| | **Write for an Academic Discussion** 学术讨论 | 教授+两学生贴 + 10 分钟 + ≥100 词 |
| 口语 | **Listen and Repeat** 跟读 | 7 句逐句：▶听→⏺录(8/10/12秒自动停)→回放 |
| | **Take an Interview** 面试 | 4 题×45 秒：▶听题→⏺录→回放 |

> 听力口音支持 **US / UK / AU / NZ**（按系统语音自动匹配）。跟读/面试与本仓库 `托福口语/` 子系统同题型，可互补。

## 评分（依官方 Overview Table 2 / 3）

- 对外报分：四科各 **1.0–6.0 band，0.5 一档；总分 = 四科平均**。
- 阅读/听力：正确率 → 折算 0–30 raw → 查**官方换算表** → band。
- 写作/口语：官方 **0–5 量规**（系统已内嵌，复制报告即带上），cc 打分后填回，自动合成 band。
- 成绩单同时给 **CEFR 等级**和 **≈ 旧制 0–120** 估分。

> 本卷为**固定仿真卷**（真考的阅读/听力是两模块自适应）。作答自动本地保存（localStorage）。

## 目录结构

```
模考系统/
├─ index.html            # 总目录（双击）
├─ build.py              # 渲染器：data/*.json → mocks/*.html + 刷新 index.html
├─ data/                 # 事实来源：每套模考 = 一个 JSON
│   └─ mock-01.json
├─ mocks/                # 生成的自包含模考页
│   └─ mock-01.html
├─ 新版题型与评分规范.md   # 9题型规格 + 官方评分量规 + JSON schema（加卷子照这个写）
└─ README.md
```

## 加一套新模考

照 `新版题型与评分规范.md` 在 `data/` 写 `<id>.json`，然后：

```bash
cd 模考系统
python3 build.py
```

刷新 `index.html` 即见。想让我出新卷，直接说「**模考加一套**」。
