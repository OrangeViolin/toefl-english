# 托福模考复习系统

每场模考后的**全盘复习**：把这场模考里遇到的生词（阅读+听力）沉淀成一张**专属背诵页**。和文字版分析（`模考复习系统/分析/`）配套，构成"一场模考 → 分析 + 生词页"的复习闭环。

## 一场模考产出两样

| 产出 | 形式 | 位置 |
|---|---|---|
| 模考分析 | Markdown | `模考复习系统/分析/<得分>-<日期>.md` |
| **模考生词页** | 自包含 HTML | 本系统 `复习页/<得分>-<日期>.html` |

## 生词页有什么

卡片：单词 · 音标 · 词性 · 释义 · **记忆钩子(词根/联想)** · **模考原句例句**(该词加粗) · 来源标签(阅读/听力) · 🔊 美音朗读。
功能：按来源筛选 · 🙈 背记模式(遮释义点开) · 只看未掌握 · 掌握进度(localStorage) · 看词选中文四选一测验。

## 工作流（喂截图 → 出页）

1. 模考后，把**内容截图**（阅读原文、听力题/文本，含你不认识的词）发给 cc。
2. cc 抽出**值得复习的词**（六级/托福级实词、学术高频词；跳过 the/and 之类），标来源、配音标/释义/钩子/原句，写进 `data/<得分>-<日期>.json`。
3. 跑 `python3 build.py` → 出 `复习页/<得分>-<日期>.html`，刷新 `index.html` 目录。

## 架构（与其它系统一致）

```
模考复习系统/
├─ build.py                    # 唯一渲染引擎，别手写 HTML
├─ data/<得分>-<日期>.json     # 每场一份词表（事实来源）
├─ 复习页/<得分>-<日期>.html   # 产出：自包含，双击即开
├─ index.html                  # 所有场次目录
└─ README.md
```

## 加页话术

「**模考复习：这场的截图**」+ 图 → cc 抽词建页。词表字段：`w/ipa/pos/zh/hook/sent/src(阅读|听力)/level`。
