Task1 木工车间跟读。病根＝实词听不住 + 长句撑不住短时记忆。每句『你说成 vs 标准』+ 为什么崩 + 木工场景词满配（点词展开）。
🔴 本科漏洞清单
  • 实词听不住：saw(锯)→serial、screwdriver(螺丝刀)→screen driver、carpentry(木工)丢——内容名词没抓住整句就塌
  • 长句(>12词)前半或后半整块丢：Q5 丢前半、Q6 丢后半——短时记忆瓶颈
  • 复述改了时态：contains→contained
🛠 补强处方
  • 慢读+分块，只盯实词(名词/动词)；先把木工场景词背熟，听到就有着落
  • 长句拆两块分别记：如 Q5『wood 要 smooth』+『用 sandpaper』两块都复述
  • 跟读照原句复述，别自作主张改时态/单复数
✓Task 1 跟读 · 木工车间（4.0/6 · 逐句）4.0/6
🗣 跟读逐句 · 你听成 vs 实际 · 怎么练
5.0
Welcome to the wood shop.
👂 你听成：Welcome to the wood shop.
🔎 ✅ 完全准确。短句、都是熟词，稳。
🗣 wood shop /wʊd ʃɑːp/ 木工车间。
4.0
This toolbox contains everything you should need.
👂 你听成：This toolbox contained everything you should need.
🔎 只错时态：contains(现在) 你说成 contained(过去)。跟读要照原句复述，别自己改时态。
🗣 contains /kənˈteɪnz/ 第三人称单数 -s，别丢也别改成过去式。
3.0
You will learn to use your saw in our classes.
👂 你听成：You will learn to use serial classes.
🔎 实词崩：your saw(你的锯子) 连读被切成 serial；『in our classes』整块丢。saw 是核心内容词，没抓住整句就塌。
🗣 saw /sɔː/ 锯子（和 sore/saw 同音）；your saw 连读别听成 serial /ˈsɪriəl/。
3.0
Your screwdriver can be used with all of our carpentry machines.
👂 你听成：Your screen driver uses our machines.
🔎 screwdriver(一个词·螺丝刀) 听成 screen driver(两个词)；『can be used with all of our carpentry』整块丢，carpentry(木工) 没抓住。
🗣 screwdriver /ˈskruːdraɪvər/ 是一个词；carpentry /ˈkɑːrpəntri/ 木工。
2.0
All wood will need to be smooth, so use the sandpaper provided.
👂 你听成：Use the sandpaper provided.
🔎 🆕 长句只复述了后半，前半『All wood will need to be smooth so』(所有木头要打磨光滑，所以)整个丢——短时记忆撑不住。练法：拆两块记『wood 要 smooth』+『用 sandpaper』。
🗣 smooth /smuːð/ 光滑（th 浊音）；sandpaper /ˈsændpeɪpər/ 砂纸。
2.0
Use only what is needed so that your supplies last all quarter.
👂 你听成：Use only what supplied it.
🔎 🆕 后半『so that your supplies last all quarter』(让物资撑满整学期)崩成 supplied it。supplies(物资)、last(撑住)、quarter(学期)都没抓。
🗣 supplies /səˈplaɪz/ 物资（名词复数）；quarter /ˈkwɔːrtər/ 学期。
4.0
Before you leave the classroom, be sure you put all your tools back into the tool box.
👂 你听成：Before you leave the classroom, be sure you put all the tools back to the toolbox.
🔎 基本对，小错：your→the、into→to。长句这次撑住了，很好。
🗣 put … back into the tool box 放回工具箱；into 别简化成 to。
🔴 你的漏洞：实词听不住 + 长句前半/后半整块丢
🛠 补强：慢读分块盯实词；长句拆两块分别复述；背木工场景词
