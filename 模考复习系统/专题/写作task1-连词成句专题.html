🔑 五句口诀 · 先背这个（全页的灵魂）

🔑 明着问就倒，藏着问不倒
单独一句问话（末尾有问号）→ 把 will/did/is 提到「谁」前面（倒装）；问话藏在 know / ask / wonder 后面 → 不提，跟平常说话一样「谁在前、动作在后」。
明着问：what will they serve?
藏着问：I know what they will serve.
🔑 Did 一出手，动词回原形
句子里出现 Did / Does / Do，后面那个动词一律用原形（Did 已经背了「过去/疑问」的锅，后面动词就不用再变）。
Did you catch up on it?　（不是 caught / discussed）
🔑 能加「被」，就 be + 过去分词
把从句翻成中文，能加个「被」字 → 用 be（is/was/were/been）+ 动词的过去分词。
被讨论 = was discussed
被达成 = have been reached
🔑 名词的小尾巴，紧贴不分家
一个名词后面拖着一段补充说明（that… / who… / 我做的…）→ 这段小尾巴紧贴名词，别甩到别处。找整句的「大动词」，它前面一整块就是主语。
The library @C{that is open 24 hours} is the best.
🔑 看时间词，定时态
yesterday / last → 过去；now / 正在 → 现在(进行)；next / will → 将来；already / yet → 完成（have + 过去分词）。先看时间词，再定动词形态。
yesterday → went／will → will go／yet → have received

🎯 摆题 3 步（每次照做）

  1. ①圈「大动词」：找整句的核心动作词（is/had/wanted/will…），它是骨架。
  2. ②找「谁」：大动词前面是谁做的；「谁」后面可能拖着小尾巴（that…/我做的…），一起当主语，别拆散。
  3. ③套口诀摆好：明着问还是藏着问？主动还是被动？什么时态？摆完数词、别留空。

📌 三个易错点 · 大白话详解

① 明着问 vs 藏着问（要不要把 will/did 提前）重点

口诀：明着问就倒，藏着问不倒
明着问（一句话就是个问题·末尾 ?）
→ 倒装：疑问词 + will/did/is + 谁
what will they serve?
where did you go?
help 词提前，谁往后放。
藏着问（跟在 know / ask / tell me 后）
→ 不倒：疑问词 + 谁 + 动作
I know what they will serve.
She asked where the class could go.
藏起来就变乖，恢复平常语序。
⏱ 一眼看：这句话本身是不是个问题（末尾问号）？是→倒装；只是嵌在别的话里→不倒。

② 主动 vs 被动（加不加 be + 过去分词）重点

口诀：能加「被」，就 be + 过去分词
主动（它自己做动作）
→ 谁 + 动作词
what resources we had used
what prompted the change
★ 疑问词自己就是「谁」时，后面直接跟动作（what prompted…）。
被动（它被…、动作落它身上）
→ 谁 + be + 过去分词
what techniques were used
what goals have been reached
is/was/were + 过去分词；完成+被动叠加 = have been + 过去分词。
⏱ 翻成中文能加「被」→ 被动。were used = 被用；we had used = 我们用了。

③ 时态（动词该用哪个形态）

口诀：Did 一出手，动词回原形　·　看时间词定时态
有 Did/Does/Do → 动词回原形
Did you catch up?（不是 caught）
Does it resolve the bugs?
助动词背了时态的锅，主动词就还原。
看时间词 → 定时态
yesterday → went
will / next → will be
yet → have received
yesterday/last=过去，next/will=将来，yet/already=完成。
⏱ 摆之前先扫一眼句子里的时间词和有没有 Did/have/be，动词形态跟着它们走。

✅ 突破清单 · 每次做题走一遍

  1. 先圈出整句的大动词（那个核心动作词）——它是骨架。
  2. 大动词前面找「谁」；注意「谁」后面可能拖着小尾巴（that…/我做的…），一起当主语，别拆。
  3. 这句本身是问题吗（末尾?）？是→倒装（will/did 提前）；藏在 know/ask 后→不倒装。
  4. 能加「被」→ be + 过去分词；有 Did/Does/Do → 后面动词回原形。
  5. 扫一眼时间词（yesterday/next/yet）定时态。
  6. 摆完数一下词，全用上、别留空（留空=0分）。
