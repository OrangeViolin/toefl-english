# 文化阅读 · 世界之窗

沉浸轴模块之一。非应试的真实阅读——文章、随笔、文化解读，把英语当成理解世界、和世界对话的窗口。**入口页**：`index.html`（双语对照 + 文化注 + 值得记的表达，自包含、点英文段可朗读）。

## 读法（每篇四步）

1. **裸读英文**：先只看英文，能懂多少懂多少（练直接用英语理解，不靠翻译）。
2. **对中文校准**：再看中文，修正误解。
3. **📌文化注**：补上"为什么他们这么想/这么说"的背景——这是"文化"而不只是"语言"的部分。
4. **抽表达**：把值得记的说法点一下入库（写作表达库），生词按项目铁律汇入背词计划。

## 数据 & 加篇

- 首批种子文内联在 `index.html` 的 `ARTICLES` 数组（`{cat,title,sub,paras:[{en,zh}],notes[],expr[]}`）；对应存档见 `文章/`。
- 话术 `文化阅读加一篇：<主题 或 文章链接>` → cc 找/整理素材、写成双语精读 + 文化注 + 抽表达。篇数多了再拆成 `data/*.json → build.py`。
- 选料方向：地道生活、文化习俗、社会观念、English-as-window 的随笔；难度贴近你当前水平、逐步上探。

## 关联

- 和 [英语思维](../英语思维/) 呼应：读到的地道说法，往往能反推出背后的思维模式。
- 和外部的 Lex 播客精读 / TED 双语互补——这个是**仓库内精选、可离线、带文化注**的一层。
