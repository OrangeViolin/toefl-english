# 日常表达 · English Living

沉浸轴模块之一。用英语写日记 / 记对话 / 记录思考与分析，把英语用进日常。**入口页**：`index.html`（含主题库）。

## 闭环（cc 批改 loop）

1. **写**：Fish 用英语写一段（日记 / 对话 / 思考）。话术 `英语日记：<英文>`。
2. **批改**：cc 保留原意，产出——
   - **地道化重写**：把中式英语、生硬搭配改成 native 说法（标出改了什么、为什么）。
   - **分级反馈**：🟢做得好的 / 🟡可提升 / 🔴明显错误，各点一两条，别面面俱到打击信心。
   - 呼应她口语心得：先肯定"敢写、写满"，再改。
3. **抽取**：从这篇里挑——
   - **值得记的表达/句型/搭配** → 汇入 `写作表达库`（话术「写作表达库加：X」的口径）。
   - **生词** → 满配汇入 `背词计划/data/项目生词.json`（对齐项目铁律，`src_from` 标「日常表达·日记」），跑 `python3 背词计划/build.py`。
4. **归档**：存 `日记/YYYY-MM-DD-<主题>.md`，模板见 `日记/2026-08-21-示例.md`。

## 归档文件结构（每篇）

```
## 原文（我写的）
...
## cc 批改
- 🟢 / 🟡 / 🔴 反馈
- 地道化重写全文
## 抽取
- 表达/句型：… → 已入写作表达库
- 生词：… → 已入背词计划
```

## 原则

- **重用起来，不重完美**：每天两三句也算数；坚持 > 篇幅。
- **产出的词一律汇入背词计划**（项目铁律，见仓库 CLAUDE.md）。
- 离线、无依赖；入口页 `index.html` 自包含。
